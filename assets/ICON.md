# ChatGames - SpigotMC Icon & Artwork

This directory contains the visual assets designed for **ChatGames**:

## 1. Minimal Pixel-Art Icons (PNG)
These icons are crafted on a native pixel art grid with crisp nearest-neighbor interpolation, suitable for direct upload as SpigotMC resource icons:
- `chatgames-icon-64.png` (64x64 PNG): Recommended size for SpigotMC resource icons.
- `chatgames-icon-128.png` (128x128 PNG): High-DPI icon used in documentation and repository headers.
- `chatgames-icon-256.png` (256x256 PNG): Extra-large icon for web showcases and Discord bots.

### Design Elements:
- **Obsidian / Slate Frame:** Dark contrasting border matching Minecraft's UI aesthetics.
- **Speech Bubble:** Clean white chat bubble representing chat trivia and word games.
- **Retro Controller:** Isometric game pad with golden amber D-pad and diamond-cyan action buttons.
- **Golden Sparkle:** Star accent signifying winning rewards and chat challenges.

## 2. High-Resolution Pixel Art Showcase
- `chatgames-art.jpg`: 1024x1024 detailed 16-bit pixel art illustration for forum banners, Modrinth gallery, or resource showcase embeds.
